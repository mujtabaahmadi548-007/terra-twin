One-time setup. The free flight-tracking feeds don't allow web pages to read them (no CORS), so aircraft come through a small helper that replaces python -m http.server 8000.
  1. Click Download helper and move terra-server.py into the folder that holds index.html.
  2. In PowerShell, stop the old server with Ctrl+C.
  3. In that folder type python terra-server.py and press Enter.
  4. Reload this page.
